# ccna-review-lab
CCNA-REVIEW-LAB


This is review lab to reinforce knowledge about HSRP and DHCP using IPV4.

R1 has been configured as an active HSRP router and R2 as the standby router. R1 has been configured with preemption. 
Moreover DHCP was set up on R1 and R2 to provide automatically  IP addresses to PCs .
